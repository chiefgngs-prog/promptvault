# SEO Content Optimization Checklist

## Before Writing
- [ ] Research target keyword (volume > 100/month)
- [ ] Check search intent (informational, commercial, transactional)
- [ ] Analyze top 10 ranking pages
- [ ] Identify content gaps
- [ ] Create outline with H2/H3 structure
- [ ] Plan internal links to/from related content

## Title Tag (50-60 chars)
- [ ] Contains primary keyword
- [ ] Under 60 characters
- [ ] Compelling and click-worthy
- [ ] Unique (not duplicate of other pages)

## Meta Description (150-160 chars)
- [ ] Contains primary keyword
- [ ] Under 160 characters
- [ ] Includes call-to-action
- [ ] Accurately describes content

## URL Structure
- [ ] Short and descriptive
- [ ] Contains primary keyword
- [ ] Uses hyphens (not underscores)
- [ ] No unnecessary parameters

## Heading Structure
- [ ] Exactly one H1 tag
- [ ] Primary keyword in H1
- [ ] Logical H2/H3 hierarchy
- [ ] Keywords in at least 2 H2s

## Content Body
- [ ] Minimum 1,500 words
- [ ] Primary keyword in first 100 words
- [ ] Natural keyword density (1-2%)
- [ ] LSI/related keywords included
- [ ] Short paragraphs (2-4 sentences)
- [ ] Bullet points or numbered lists
- [ ] Bold/italic for emphasis
- [ ] Table or data visualization
- [ ] Original analysis or opinion

## Images
- [ ] At least 2 relevant images
- [ ] Descriptive alt text with keywords
- [ ] Compressed file size (< 100KB)
- [ ] Descriptive file name (keyword-based)

## Links
- [ ] 3-5 internal links to related content
- [ ] 1-2 external links to authoritative sources
- [ ] All links open in same tab
- [ ] No broken links

## Technical
- [ ] Page loads in under 3 seconds
- [ ] Mobile responsive
- [ ] HTTPS enabled
- [ ] Schema markup (Article type)
- [ ] Canonical tag set
- [ ] XML sitemap updated

## After Publishing
- [ ] Submit to Google Search Console
- [ ] Share on social media
- [ ] Build at least 1 backlink
- [ ] Monitor rankings for 30 days
- [ ] Update content after 90 days
