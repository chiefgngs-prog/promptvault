Free ChatGPT Prompts for Data Analysts

You pull the data, clean it, model it, and then face the hardest part: explaining what it means to someone who does not speak SQL or statistics. Stakeholders want the answer and the action, not the query plan. Meanwhile you are also writing documentation, drafting data definitions, debugging queries, and translating a chart into a recommendation. ChatGPT is surprisingly strong on the communication side of analytics — explaining a result in plain language, suggesting what a dashboard should show, writing starter SQL from a description, or summarizing a month of metrics into a short narrative. It is not reliable for the math itself, so these prompts are built to help you explain, document, and structure analysis you have already validated, not to replace your calculations. Feed it your findings or your table schema, review anything code-related before you run it, and let it carry the prose. Choose your prompt below.

13 Free Prompts

Data Cleaning Pipeline

I have a dataset about [DESCRIBE DATA] with issues: [MISSING VALUES, DUPLICATES, OUTLIERS, FORMATTING]. Create a step-by-step data cleaning pipeline: identify and handle missing values (imputation strategy), remove duplicates, detect and treat outliers (with justification), standardize formats, validate data types, and document all changes. Provide Python code.

SQL Query Optimizer

Optimize this SQL query for performance: [PASTE QUERY]. Table structure: [DESCRIBE]. Analyze: full table scans, missing indexes, inefficient JOINs, subquery vs CTE, unnecessary columns, WHERE clause efficiency, and GROUP BY optimization. Rewrite the query, explain each change, suggest indexes to create, and estimate performance improvement.

Exploratory Data Analysis Plan

Create an EDA plan for my dataset about [DESCRIBE DOMAIN] with [NUMBER] rows and columns: [LIST COLUMNS]. Outline: summary statistics to compute, distributions to visualize (and chart types), correlations to explore, group-by analysis, time-series patterns (if applicable), outlier investigation, missing data analysis, and 5 key questions the data should answer.

Dashboard Design Blueprint

Design a [BUSINESS INTELLIGENCE / ANALYTICS] dashboard for [AUDIENCE] tracking [METRICS/KPIs]. Specify: layout grid, widget placement (top KPIs at top-left, trend charts below, detail tables at bottom), chart types for each metric, color scheme (max 5 colors), filter/slicer design, drill-down paths, refresh frequency, and annotation/note features.

A/B Test Designer

Design an A/B test for [WHAT YOU'RE TESTING] on [PLATFORM]. Define: hypothesis (null and alternative), primary metric, secondary metrics, minimum detectable effect, sample size calculation, test duration, traffic split, randomization method, success criteria, guardrail metrics, and analysis plan (statistical test, significance level, power).

Statistical Analysis Guide

I need to analyze data to answer: [RESEARCH QUESTION]. Data: [DESCRIBE]. Recommend: the appropriate statistical test (t-test, ANOVA, chi-square, regression, etc.) with justification, assumptions to verify, how to handle violations, effect size measure, software/code to use, interpretation guidelines, and how to report results to non-technical stakeholders.

Data Storytelling Framework

Transform these analysis findings into a compelling data story for [AUDIENCE]: [PASTE FINDINGS]. Structure: start with the hook (why should they care?), context (what we analyzed), key insight (the 'aha' moment), supporting evidence (2-3 visuals described), implications (what it means for them), recommended actions, and potential objections. Use the Minto Pyramid principle.

Machine Learning Model Selector

I want to predict [TARGET] from [DESCRIBE FEATURES]. Data size: [ROWS x COLUMNS]. Task type: [CLASSIFICATION/REGRESSION/CLUSTERING]. Recommend 3 suitable algorithms ranked by suitability. For each: why it fits, pros and cons, data preprocessing requirements, hyperparameters to tune, expected performance, and Python code to implement.

Customer Churn Analysis Plan

Create a churn analysis plan for [BUSINESS TYPE - SaaS/E-commerce/App]. Identify: definition of churn, data needed (usage, transactions, demographics, support tickets), features to engineer (recency, frequency, monetary, tenure, engagement trends), analysis approach (descriptive → predictive), retention strategy framework, and reporting cadence for stakeholders.

Revenue Forecasting Model

Build a revenue forecasting model for [BUSINESS TYPE]. Inputs available: [DESCRIBE DATA]. Recommend: forecasting method (time series, regression, ML), decomposition (trend, seasonality, cyclical, irregular), driver identification, scenario planning (base/upside/downside), confidence intervals, refresh frequency, and presentation format for executives.

Cohort Analysis Template

Design a cohort analysis for [BUSINESS TYPE - SaaS, e-commerce, mobile app]. Define: cohort grouping (sign-up date, first purchase, acquisition channel), metric to track (retention, revenue, engagement), time granularity (weekly/monthly), visualization format (heatmap/triangle table), insights to extract, and retention benchmarks. Provide SQL or Python template.

Funnel Analysis Builder

Create a conversion funnel analysis for [PRODUCT/SERVICE]. Steps: [DEFINE FUNNEL STAGES]. For each stage: define the event/condition, identify drop-off causes, benchmark conversion rate, suggest 3 optimization experiments, and estimate revenue impact of improving each stage by 10%. Include attribution model considerations and time-delay analysis.

Data Dictionary Creator

Create a comprehensive data dictionary for my dataset. Columns: [LIST]. For each column: provide field name, data type, description, allowed values/range, source, example value, null handling, transformation rules, dependencies, and PII/sensitivity classification. Format as a table. Add a section for data quality rules and validation checks.
