Keyword Research Prompts

1. Full Keyword Strategy

Prompt: Create a keyword research strategy for [WEBSITE/INDUSTRY]. Include: seed keywords (20), long-tail opportunities (30), question-based keywords (15), commercial keywords (10), keyword clustering approach, search intent mapping, and prioritization framework.

2. Content Cluster Designer

Prompt: Design a topic cluster strategy for [CORE TOPIC]. Include: 1 pillar page concept, 15-20 cluster content topics, internal linking structure, keyword mapping for each page, content brief template, and publishing schedule.

Content Optimization Prompts

3. SEO Article Writer

Prompt: Write an SEO-optimized article about [TOPIC]. Primary keyword: [KEYWORD]. Secondary keywords: [KEYWORDS]. Include: optimized H1, structured H2/H3 headings, meta description, FAQ section, internal linking suggestions, and natural keyword placement. 1500-2000 words.

4. SEO Content Brief

Prompt: Create a detailed SEO content brief for [TARGET KEYWORD]. Include: search intent, target word count, title options, heading structure, entities/LSI keywords to include, internal linking targets, external linking suggestions, and SERP analysis insights.

Technical SEO Prompts

5. Technical SEO Audit

Prompt: Create a technical SEO audit checklist for [WEBSITE TYPE]. Include: site speed analysis, mobile-friendliness, crawlability, indexability, XML sitemap, robots.txt, canonical tags, hreflang, structured data, Core Web Vitals, and JavaScript SEO considerations.

6. Core Web Vitals Optimization

Prompt: Create a Core Web Vitals optimization guide for [WEBSITE TYPE]. Address: LCP (Largest Contentful Paint), FID/INP (Interaction to Next Paint), CLS (Cumulative Layout Shift). For each metric: explain it, identify common issues, and provide specific fixes.

Link Building Prompts

7. Backlink Strategy

Prompt: Create a backlink building strategy for [WEBSITE] in [INDUSTRY]. Include: linkable asset ideas (5), outreach strategy, guest posting targets (criteria), broken link building approach, HARO strategy, directory submissions, and competitor backlink analysis method.

8. Link Building Outreach Templates

Prompt: Write 5 link building outreach email templates for [WEBSITE/CONTENT]. Use different approaches: value-first, resource suggestion, broken link, guest post pitch, and collaboration. Include subject lines, body copy, follow-up sequence, and personalization tokens.

Local SEO Prompts

9. Local SEO Strategy

Prompt: Create a local SEO strategy for [BUSINESS TYPE] in [CITY]. Include: Google Business Profile optimization, local keyword targets, review acquisition strategy, local citation building, location page optimization, and community engagement tactics.
