Code Review

Prompt:Act as a senior software engineer. Review this code: [PASTE CODE]. Analyze for: code quality, performance issues, security vulnerabilities, best practices, potential bugs, edge cases, and maintainability. Provide specific improvement suggestions with code examples.

System Architecture

Prompt:Design a system architecture for [APPLICATION]. Include: high-level architecture diagram (text-based), technology stack recommendations, database schema, API endpoint structure, scaling strategy, security considerations, and deployment approach.

Debugging

Prompt:Debug this error: [ERROR MESSAGE]. Code: [PASTE CODE]. Analyze: possible root causes, step-by-step debugging approach, common pitfalls for this scenario, and provide the fix with explanation. Include prevention tips.

Unit Tests

Prompt:Write comprehensive unit tests for this function: [PASTE CODE]. Use [FRAMEWORK]. Include: happy path tests, edge case tests, error handling tests, boundary tests, and mock setup. Aim for 100% code coverage.

Database Schema Design

Prompt:Design a complete database schema for [APPLICATION TYPE]. Include: all tables with columns and types, primary/foreign key relationships, indexes for optimization, normalization considerations, sample queries, and an ER diagram (text-based).

Security Audit

Prompt:Perform a security audit for [APPLICATION TYPE/TECH STACK]. Check for: SQL injection, XSS, CSRF, authentication flaws, authorization issues, sensitive data exposure, security headers, dependency vulnerabilities, and API security.

Docker Setup

Prompt:Create a complete Docker setup for [APPLICATION]. Include: Dockerfile (multi-stage build), docker-compose.yml, .dockerignore, environment configuration, volume management, and deployment notes.
